# Считалка фреймов

Быстро подсчитает число фреймов высокого уровня с вашими макетами

---

Плагин для Pixso, выполняющий одно простейшее действие — подсчет числа фреймов (объектов типа FRAME) высшего уровня. Решает задачу ускорения подсчета объема работы по модификации всех дизайнов на всех экранах внутри файла с макетами. Работает с фреймами внутри секций, исключает все фреймы внутри других фреймов, не учитывает скрытые (hiden) фреймы. Считает все фреймы на всех страницах (page) файла.

Особенности:
- версия для Pixso Private Deployment в организации;
- поддерживает Plugin API в версиях 1.86.x и 2.xx;
- без публикации в Pixso Global.
